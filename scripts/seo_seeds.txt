# Seed titles for the public "books like X" pages.
#
# Format: `Title | Author`. Everything after a # is a comment; blank lines and
# duplicate titles are dropped. Order doesn't matter.
#
# THE AUTHOR IS NOT OPTIONAL IN PRACTICE. Titles are not unique: a bare
# "The Fifth Season" resolves to a Vermont detective novel rather than
# Jemisin's, and a page built on the wrong book is worse than no page at all.
# When an author is given, records that don't match it are rejected outright,
# so a seed that can't be resolved is skipped instead of guessed at.
# Surname matching is what's used, so initials and formatting don't matter.
#
# What belongs here: books people actually search "books like ___" for, in the
# genres this recommender scores well. That's not an accident of taste — the
# same popular titles are the ones with rich Google Books / Open Library
# metadata, which is exactly what the scorer needs. Obscure and self-published
# serials (the known data wall in CLAUDE.md) will fail the publish gate and
# waste a lookup, so leave them out.
#
# Roughly half of these clear the publish gate on a given run; that's the gate
# working, not a bug. Adding lines here is the main growth lever — every new
# one is a potential search landing page. Re-run the generator after editing.
